# DevLinks

> 🔧 **Projeto**  
> DevLinks é um projeto front-end que organiza links úteis para desenvolvedores. O objetivo é ter uma página simples onde o usuário pode acessar recursos relevantes em categorias.

## Descrição

DevLinks é uma aplicação web estática construída com **HTML, CSS e JavaScript**.  
O projeto foi criado como parte de um desafio/atividade da Rocketseat para praticar desenvolvimento web e habilidades com estrutura de arquivos, layout e manipulação de DOM.

Ele funciona como uma **lista de links úteis**, organizada de forma visual, onde o visitante pode acessar rapidamente recursos que interessam a desenvolvedores.

## Tecnologias Utilizadas

- **HTML** — estrutura da página
- **CSS** — estilo e layout visual
- **JavaScript** — interação e comportamento dinâmico básico

## Funcionalidades

Atualmente o projeto inclui:
- Exibição de uma página com links úteis
- Estilo visual responsivo básico
- Código organizado em arquivos separados

*(O projeto não possui backend nem integração com servidor.)*

## Como executar

Basta abrir o arquivo `index.html` em um navegador moderno.

1. Clone o repositório:
   ```bash
   git clone https://github.com/RafaelAdamRamos/DevLinks.git

2. Acesse a pasta:

   ```bash
   cd DevLinks
   ```
3. Abra o arquivo:

   * Dê um duplo clique em `index.html`
   * ou execute com um servidor estático (ex: live server no VSCode)
